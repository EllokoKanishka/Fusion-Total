# Security policy

Fusion Reader v2 is local-only by default. Please report vulnerabilities
privately to the repository owner through GitHub's private vulnerability
reporting channel when available; do not include private documents, tokens or
voice samples in a public issue.

Supported security fixes target the active `fusion_reader_v2/` product. See
[docs/SECURITY.md](docs/SECURITY.md) for the threat boundaries, stored data,
cleanup procedures and safe remote-access requirements.
