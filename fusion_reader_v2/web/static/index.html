Órdenes que entiende

El dictado normal se escribe literalmente. Para ejecutar una acción, podés decir la frase completa —“Lucy, borrá X”— o decir sólo “Lucy”, hacer una pausa y dictar la orden cuando aparezca Lucy está escuchando tu orden. También entiende “Lucy, borrá 10 palabras”, “Lucy, cambiá las últimas 20 palabras por Y”, “Lucy, reemplazá X por Y”, “Lucy, deshacer”, “Lucy, pará acá”, “Lucy, léeme el último párrafo”, “Lucy, léeme la última hoja” o “Lucy, léeme desde X”. Si desactivás Órdenes con «Lucy», todo lo oído entra como texto.
