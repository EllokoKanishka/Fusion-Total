# Archivo histórico

Esta carpeta guarda materiales viejos o de auditoría que ya no son fuente viva
de estado operativo. Los blueprints, mediciones, workbooks y tableros que fueron
retirados de la raíz se conservan aquí para mantener trazabilidad sin competir
con la documentación canónica.

1. `AGENTS.md`
2. `FUSION_READER_V2_STATE.md`
3. `docs/ARCHITECTURE.md`
4. `docs/OPERATIONS.md`
5. `docs/CONTRACTS.md`
